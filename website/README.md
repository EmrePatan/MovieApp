# Movie Cave public website

Static site for **https://moviecaveapp.com**.

## Routes

- `/` — landing page
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Service
- `/delete-account/` — account deletion instructions (Google Play URL)

## Commands

```bash
npm ci
npm run build
npm run preview   # optional local Wrangler preview
```

See [CLOUDFLARE-DEPLOYMENT.md](./CLOUDFLARE-DEPLOYMENT.md) for Cloudflare Workers Git deployment settings.
